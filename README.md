# Face Mask Detection 🎭

A deep learning project that detects whether a person is wearing a face mask or not using a CNN-based image classifier.

## 🧠 Project Overview
This project uses computer vision and convolutional neural networks (CNNs) to classify images into two categories: **Mask** and **No Mask**. It supports both image input and real-time webcam detection.

## 🧹 Data Preprocessing
- Resized all images to a fixed dimension
- Applied data augmentation (rotation, zoom, flip)
- Normalized pixel values for faster convergence
- Split dataset into training and validation sets

## 🛠️ Technologies Used
- Python  
- TensorFlow & Keras  
- OpenCV  
- NumPy  
- Matplotlib  

## 🚀 Features
- Real-time mask detection using webcam
- High accuracy binary classification
- Easily extendable to multi-class classification
